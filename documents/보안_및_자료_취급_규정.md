# 연구기관 보안 및 자료 취급 규정

이 문서는 Private RAG 실습을 위해 만든 가상의 규정이다. 실제 기관의 규정으로
사용하지 않는다.

## 규칙 01. 개인 계정 사용

업무 시스템에는 본인에게 발급된 개인 계정으로만 접속한다. 계정을 다른 사람과
공유하거나 공용 비밀번호를 사용해서는 안 된다.

## 규칙 02. 비밀번호 관리

비밀번호는 12자 이상으로 설정하고 다른 서비스에서 사용한 비밀번호를 재사용하지
않는다. 비밀번호가 노출된 것으로 의심되면 즉시 변경한다.

## 규칙 03. 다중 인증

외부에서 업무 시스템에 접속할 때에는 비밀번호 외에 승인 앱이나 보안 키를 이용한
다중 인증을 추가로 수행한다.

## 규칙 04. 화면 잠금

자리를 비울 때에는 컴퓨터 화면을 잠근다. 공유 공간에서는 화면에 민감한 연구 정보가
노출되지 않도록 주의한다.

## 규칙 05. 권한 최소화

사용자에게는 현재 업무에 필요한 최소한의 접근 권한만 부여한다. 업무가 바뀌면 더 이상
필요하지 않은 권한을 회수한다.

## 규칙 06. 문서 등급 표시

연구 문서는 공개, 내부, 제한, 기밀 중 하나의 등급을 표시한다. 등급이 없는 문서는
작성자에게 확인하기 전까지 내부 문서로 취급한다.

## 규칙 07. 내부 문서 공유

내부 문서는 기관 계정으로 로그인한 사용자에게만 공유한다. 공개 링크를 만들어
외부에 전달해서는 안 된다.

## 규칙 08. 제한 문서 열람

제한 문서는 소속 부서장과 문서 책임자가 승인한 사용자만 열람할 수 있다. 열람 기록은
감사 로그에 남긴다.

## 규칙 09. 기밀 문서 출력

기밀 문서를 출력하려면 문서 책임자의 사전 승인을 받아야 한다. 출력물에는 문서 등급과
출력자 이름을 표시한다.

## 규칙 10. 문서 폐기

보존 기간이 끝난 종이 문서는 보안 파쇄함에 넣고 전자 문서는 승인된 삭제 절차로
폐기한다. 일반 휴지통이나 개인 클라우드에 옮겨서는 안 된다.

## 규칙 11. 외부 저장 장치 등록

업무용 USB와 외장 디스크는 자산 관리 목록에 등록한 뒤 사용한다. 등록되지 않은 저장
장치는 업무용 컴퓨터에 연결할 수 없다.

## 규칙 12. 저장 장치 암호화

내부 자료를 저장하는 이동식 저장 장치는 전체 디스크 암호화를 적용한다. 암호화가
해제된 장치에는 내부 자료를 복사할 수 없다.

## 규칙 13. USB 외부 반출

업무용 USB를 기관 밖으로 반출하려면 정보 보안 담당자의 사전 승인을 받아야 한다.
반출 신청에는 목적, 반출 기간, 저장 자료 목록을 기록한다.

## 규칙 14. 저장 장치 반입 검사

외부에서 사용한 저장 장치를 다시 연결하기 전에 악성 코드 검사를 수행한다. 이상이
발견되면 장치를 분리하고 보안 담당자에게 신고한다.

## 규칙 15. 저장 장치 분실

USB나 외장 디스크를 분실하면 발견 여부와 관계없이 즉시 보안 담당자에게 신고한다.
분실 시각, 장소, 저장 자료의 등급을 함께 알린다.

## 규칙 16. 원격 접속

기관 외부에서 내부 시스템에 접속할 때에는 승인된 가상 사설망을 사용한다. 개인용
원격 제어 프로그램을 설치해 우회 접속해서는 안 된다.

## 규칙 17. 공용 무선망 사용

공항이나 카페의 공용 무선망에서는 기밀 문서를 열람하지 않는다. 업무 접속이 필요하면
기관이 승인한 보안 연결을 먼저 사용한다.

## 규칙 18. 방화벽 변경

방화벽 규칙과 외부 공개 포트는 시스템 관리자의 승인을 받아 변경한다. 임시로 연 포트도
작업이 끝나면 즉시 닫는다.

## 규칙 19. 외부 서비스 연동

외부 소프트웨어 서비스에 내부 데이터를 전송하려면 보안성 검토를 받아야 한다. 서비스의
저장 위치, 보존 기간, 삭제 방법을 확인한다.

## 규칙 20. API 인증 정보

API 키와 접근 토큰은 소스 코드나 문서에 직접 적지 않는다. 승인된 비밀 정보 저장소에
보관하고 노출되면 즉시 폐기한 뒤 다시 발급한다.

## 규칙 21. 연구 데이터 수집

연구 데이터는 승인된 연구 목적에 필요한 범위에서만 수집한다. 수집 항목과 이용 목적을
연구 계획서에 기록한다.

## 규칙 22. 개인정보 비식별화

분석에 개인 식별 정보가 필요하지 않으면 이름, 전화번호, 전자우편 주소를 제거하거나
대체값으로 변환한 뒤 사용한다.

## 규칙 23. 학습 데이터 반출

모델 학습 데이터를 외부 컴퓨팅 환경으로 옮기려면 데이터 책임자와 정보 보안 담당자의
승인을 모두 받아야 한다.

## 규칙 24. 외부 생성형 AI 사용

공개형 생성 AI 서비스에는 내부, 제한, 기밀 등급의 문서를 입력하지 않는다. 공개 정보만
사용하더라도 서비스 이용 약관과 데이터 보존 정책을 확인한다.

## 규칙 25. 연구 결과 공개

논문, 발표 자료, 공개 저장소에 연구 결과를 올리기 전에 기밀 정보와 개인정보가 포함되지
않았는지 검토하고 연구 책임자의 승인을 받는다.

## 규칙 26. 보안 사고 신고

자료 유출이나 계정 침해가 의심되면 사실 확인이 끝날 때까지 기다리지 않고 즉시 보안
담당자에게 신고한다. 발견 시각과 관찰한 현상을 함께 전달한다.

## 규칙 27. 악성 메일 대응

의심스러운 첨부 파일이나 링크를 열지 않는다. 발신자가 아는 사람이어도 요청 내용이
평소와 다르면 다른 연락 수단으로 확인한다.

## 규칙 28. 로그 보존

업무 시스템의 접속 기록과 주요 작업 기록은 1년 동안 보존한다. 조사 대상 로그는 보존
기간이 지나더라도 조사 종료 전까지 삭제하지 않는다.

## 규칙 29. 퇴직자 계정

퇴직자의 업무 계정은 마지막 근무일이 끝나는 시점에 비활성화한다. 인수인계가 필요하면
계정을 공유하지 않고 자료 소유권을 승인된 담당자에게 이전한다.

## 규칙 30. 정기 점검

부서별 문서 접근 권한과 외부 공유 상태를 분기마다 점검한다. 불필요한 권한과 만료된
공유 링크는 점검 과정에서 회수한다.
